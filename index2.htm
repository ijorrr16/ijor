01 · KONSEP DASAR

Apa Itu Struktur Atom?

Struktur atom adalah susunan partikel penyusun atom, yaitu proton dan neutron di dalam inti atom serta elektron yang berada di sekitar inti.

Proton bermuatan positif, neutron tidak bermuatan, dan elektron bermuatan negatif. Jumlah serta susunan partikel ini membantu menjelaskan identitas dan sifat atom.

Nomor atom menunjukkan jumlah proton, sedangkan nomor massa merupakan jumlah proton dan neutron dalam inti atom.
02 · PERKEMBANGAN TEORI

Perkembangan Teori Atom

⚪

Model Atom Dalton

Dalton menggambarkan atom sebagai bola pejal yang sangat kecil dan tidak dapat dibagi melalui reaksi kimia biasa.

  • Atom digambarkan sebagai bola pejal.
  • Atom suatu unsur memiliki ciri khas.
  • Senyawa terbentuk dari gabungan atom dengan perbandingan tertentu.
🍮

Model Atom Thomson

Thomson menemukan elektron dan mengusulkan model atom berupa muatan positif dengan elektron tersebar di dalamnya, sering dianalogikan seperti roti kismis.

  • Atom mengandung elektron bermuatan negatif.
  • Muatan positif tersebar dalam modelnya.
  • Atom secara keseluruhan bersifat netral.
03 · MODEL ATOM

Model Atom Rutherford dan Bohr

Rutherford menyimpulkan bahwa atom memiliki inti kecil bermuatan positif dan sebagian besar volumenya merupakan ruang kosong. Bohr kemudian mengusulkan bahwa elektron berada pada tingkat energi tertentu.

Model Rutherford menjelaskan keberadaan inti atom, sedangkan model Bohr memperkenalkan tingkat energi elektron. Model atom modern menjelaskan elektron melalui orbital atau daerah kebolehjadian menemukan elektron.

04 · PERBANDINGAN

Perbandingan Model-Model Atom

Model Atom Gagasan Utama Keterbatasan
Dalton Atom berupa bola pejal; atom tiap unsur memiliki ciri khas. Belum mengenal partikel subatom.
Thomson Elektron tersebar dalam muatan positif (model roti kismis). Belum menjelaskan keberadaan inti atom.
Rutherford Atom memiliki inti kecil bermuatan positif dan sebagian besar berupa ruang kosong. Belum menjelaskan kestabilan atom dan spektrum garis.
Bohr Elektron menempati tingkat energi tertentu. Terutama cocok untuk menjelaskan atom hidrogen.
Model modern Elektron dijelaskan melalui orbital atau daerah kebolehjadian. Tidak menggambarkan lintasan elektron yang pasti seperti planet.
05 · PARTIKEL ATOM

Partikel Penyusun Atom dan Notasi Atom

Atom tersusun atas proton, neutron, dan elektron. Nomor atom (Z) menunjukkan jumlah proton, sedangkan nomor massa (A) adalah jumlah proton dan neutron.

Nomor massa (A) = jumlah proton + jumlah neutron

Hubungan partikel pada atom netral:

Nomor atom (Z) = jumlah proton

Atom netral: jumlah proton = jumlah elektron

Jumlah neutron = nomor massa (A) − nomor atom (Z)

Pada atom netral, jumlah proton sama dengan jumlah elektron. Jika atom melepas atau menerima elektron, terbentuk ion positif (kation) atau ion negatif (anion).

06 · KONSEP KUNCI

Konsep Penting Struktur Atom

  1. Partikel subatom
    • Proton: muatan +1, berada di inti.
    • Neutron: muatan 0, berada di inti.
    • Elektron: muatan −1, berada di sekitar inti.
  2. Nomor atom (Z): jumlah proton dalam inti atom.
  3. Nomor massa (A): jumlah proton dan neutron dalam inti atom.
  4. Isotop: atom dengan nomor atom sama, tetapi nomor massa berbeda.
